# Windows Process Management Tool

A simple Batch Script utility for Windows administrators and IT support engineers.

## Features

- View Chrome process instances
- Kill all Chrome processes
- View Edge process instances
- Kill all Edge processes
- View Firefox process instances
- Kill all Firefox processes
- Display all running processes
- Kill any process by name

## Requirements

- Windows 10 / 11
- Administrator privileges (recommended)

## Usage

1. Download the repository.
2. Run `ProcessManager.bat`
3. Select an option from the menu.
